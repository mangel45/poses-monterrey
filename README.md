# Poses Monterrey

Guía de poses para fotos en Monterrey. Elige quién posa (hombre, mujer o pareja) y el lugar, abre el visor y acomoda la silueta de la pose sobre la cámara en vivo o sobre una foto del lugar.

Abrir la app: https://mangel45.github.io/poses-monterrey/

Es una sola página (`index.html`), sin dependencias ni servidor. La cámara en vivo necesita HTTPS, por eso se sirve con GitHub Pages.
